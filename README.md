ATELIER DE TISSAGE — VERSION 2 (prototype PWA)

Contenu :
- index.html : structure de l'application
- style.css : interface adaptative iPhone/iPad
- app.js : moteur de dessin, passage, attachage, marchure, couleurs, sauvegarde locale et JSON
- manifest.json : paramètres d'installation PWA
- service-worker.js : cache pour fonctionnement hors ligne après premier chargement

Pour tester :
1. Héberger ce dossier sur un serveur HTTPS (ex. GitHub Pages ou Netlify).
2. Ouvrir l'adresse dans Safari sur iPhone/iPad.
3. Utiliser Partager > Sur l'écran d'accueil.

Note : prototype en développement. Les couleurs sont une palette prédéfinie. L'export Excel et une bibliothèque multi-patrons ne sont pas encore intégrés. L'export JSON est recommandé pour conserver une copie externe.
